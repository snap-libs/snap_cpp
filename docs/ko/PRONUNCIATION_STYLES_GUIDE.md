# 🎙️ SNAP 한국어 3대 발음 스타일 가이드 (Pronunciation Styles Guide)

SNAP(Speech Normalization & Phonology) 엔진은 서비스 목적과 발화 시나리오(공식 뉴스, 일반 안내, 일상 대화, 챗봇 캐릭터)에 맞추어 **동일한 텍스트에 대해 세 가지 발음 스타일 모드(`pronunciation_style`)**를 제공합니다.

---

## 📌 1. 3대 발음 모드 개요

| 발음 모드 | 명칭 | 기본 여부 | 주 적용 시나리오 | 핵심 특징 |
|:---|:---|:---:|:---|:---|
| **`modern_standard`** | **현대 표준음** | **기본값** | 뉴스 브리핑, 오디오북, AI 음성 비서, 공식 안내 방송 | 국립국어원 표준국어대사전 표제음 및 대중적 수용성이 높은 현대 표준 규범을 준수합니다. |
| **`strict_standard`** | **엄격 규범음** | 선택 | 역사 다큐멘터리, 고문서 낭독, 법률 조문, 국어 교육 | 모음 축약이나 현실음을 배제하고, 원칙 표기와 철자 본래의 음가를 엄격히 보존합니다. |
| **`colloquial`** | **일상 구어체** | 선택 | AI 캐릭터 챗봇, 게임/웹툰 대사, 드라마, 일상 회화 | 한국어 원어민의 실제 입말 발화 습관(단모음화, 'ㅎ' 연음, 연구개음화)을 자연스럽게 반영합니다. |

## ⚖️ 2. 핵심 6대 음운 변동 구분 기준

각 모드는 국립국어원 『표준 발음법』 조항에 근거하여 음운 규칙의 적용 범위가 명확히 분기됩니다.

```
                  [음운 규칙 적용 강도]
 strict_standard   ◄───────   modern_standard   ───────►   colloquial
  (원칙음 고수)                 (현대 규범음)                 (자연 구어체)
```

| 음운 변동 영역 | `strict_standard` | `modern_standard` (기본) | `colloquial` | 표준 규범 근거 |
|:---|:---|:---|:---|:---|
| **1. 한자어 사잇소리** | **평음 원칙**<br>• `효과 [효과]`<br>• `교과서 [교과서]` | **사전 표제음**<br>• `효과 [효꽈]`<br>• `교과서 [교꽈서]` | **된소리**<br>• `효과 [효꽈]`<br>• `교과서 [교꽈서]` | 국립국어원 복수 표준 발음 고시 (`[효ː과]/[효ː꽈]`) |
| **2. 한자어 경음화 (제26항)** | **규범 된소리**<br>• `결정 [결쩡]`<br>• `발생 [발쌩]` | **규범 된소리**<br>• `결정 [결쩡]`<br>• `발생 [발쌩]` | **규범 된소리**<br>• `결정 [결쩡]`<br>• `발생 [발쌩]` | 제26항: 'ㄹ' 받침 뒤 'ㄷ, ㅅ, ㅈ' 된소리화 |
| **3. 외래어 관용음** | **원어 평음**<br>• `버스 [버스]`<br>• `서비스 [서비스]` | **대중 관용음**<br>• `버스 [뻐스]`<br>• `서비스 [써비스]` | **대중 관용음**<br>• `버스 [뻐스]`<br>• `서비스 [써비스]` | 외래어 표기법 원칙 vs 실제 한국인 관용 발화 |
| **4. 관형격 조사 '의'** | **원칙음**<br>• `나의 [나의]`<br>• `국민의 [궁민의]` | **허용음**<br>• `나의 [나에]`<br>• `국민의 [궁미네]` | **허용음**<br>• `나의 [나에]`<br>• `국민의 [궁미네]` | 제5항 다만 4: 조사 '의'는 [ㅔ] 발음 허용 |
| **5. 모음 'ㅖ' 단모음화** | **원칙 이중모음**<br>• `지혜 [지혜]`<br>• `시계 [시계]`<br>• `차례 [차례]` | **원칙 이중모음**<br>• `지혜 [지혜]`<br>• `시계 [시계]`<br>• `차례 [차례]` | **구어 단모음화**<br>• `지혜 [지헤]`<br>• `시계 [시게]`<br>• `차례 [차레]` | 제5항 다만 2: '예, 례' 외의 'ㅖ'는 [ㅔ] 허용 |
| **6. 'ㅎ' 약화 및 연음** | **[ㅎ] 보존**<br>• `전화 [전화]`<br>• `일하다 [일하다]` | **[ㅎ] 보존**<br>• `전화 [전화]`<br>• `일하다 [일하다]` | **구어 약화/연음**<br>• `전화 [저놔]`<br>• `일하다 [이라다]` | 제12항 [붙임 2]: [ㅎ] 발음이 원칙이나 구어 약화 발생 |
| **7. 자음동화 (비음화)** | **원형 보존**<br>• `감기 [감기]`<br>• `신문 [신문]` | **원형 보존**<br>• `감기 [감기]`<br>• `신문 [신문]` | **연구개/양순음화**<br>• `감기 [강기]`<br>• `신문 [심문]` | 구어체 수의적 자음동화 현상 |

## 💻 4. 사용 방법 (API & SDK Integration)

### 1) C++ Native API (`snap_process_ext`)
인메모리 JSON 옵션 문자열을 통해 문장별로 무지연(Zero-Disk-IO) 스타일을 지정합니다:

```cpp
#include "snap/snap_api.h"

void* engine = snap_create("c:/work/snap", "ko");

// 1. 기본 현대 표준음 (modern_standard)
const char* res_modern = snap_process_ext(engine, "새로운 혜택을 발표했다.", "{}");
// 결과: "새로운 혜태글 발표핻따."

// 2. 일상 구어체 (colloquial)
const char* res_colloq = snap_process_ext(engine, "새로운 혜택을 발표했다.", 
    "{\"pronunciation_style\": \"colloquial\"}");
// 결과: "새로운 헤태글 발표핻따."

// 3. 엄격 규범음 (strict_standard)
const char* res_strict = snap_process_ext(engine, "새로운 혜택을 발표했다.", 
    "{\"pronunciation_style\": \"strict_standard\"}");
// 결과: "새로운 혜태글 발표핻따."

snap_free((void*)res_modern);
snap_free((void*)res_colloq);
snap_free((void*)res_strict);
snap_destroy(engine);
```

### 2) 글로벌 설정 파일 (`models/snap_config.json`)
서버 부팅 시 기본 발음 스타일을 고정하고자 할 경우 설정합니다:

```json
{
    "ko": {
        "pronunciation_style": "modern_standard",
        "vowel_length": false,
        "to_ipa": false,
        "to_ssml": false
    }
}
```

### 3) Python REST API 클라이언트
```python
import requests

payload = {
    "text": "파트너를 위한 다양한 혜택과 교육 기회를 제공합니다.",
    "config": {
        "pronunciation_style": "colloquial",  # "modern_standard" | "strict_standard"
        "lang": "ko"
    }
}

res = requests.post("https://snap-api-673324870645.asia-northeast3.run.app/v1/normalize", json=payload).json()
print(res["data"]["phonemes"])
```
