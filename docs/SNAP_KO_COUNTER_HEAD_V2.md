# 📘 SNAP 한국어 2-Layer MLP Counter Head (V2) 기술 명세서

본 문서는 SNAP 엔진의 한국어 다의어 수량사/식별자 판별을 전담하는 **2-Layer MLP Counter Head (`KO_model_counter.onnx`)**의 신경망 구조, 학습 데이터셋, 정확도 벤치마크 및 하이브리드 추론 파이프라인을 정의합니다.

---

## 📌 1. 개요 (Overview)

한국어 숫자 발음은 동일한 단위 명사라도 문맥(수량/빈도 vs 순서/서열/식별자)에 따라 고유어(NATIVE)와 한자어(SINO)로 갈리는 **8대 다의어 카운터 단위**를 가집니다.

* **기존 1-Layer Linear Head의 한계**: 선형 결합만으로는 '차량 3대(세 대)'와 '주요 3대 과제(삼대 과제)' 같은 복합 명사구 문맥의 비선형 특징을 분리하지 못해 약 88% 수준에서 정체됨.
* **V2 2-Layer MLP Head의 혁신**: 768차원 BERT 히든 벡터를 `LayerNorm + GELU` 비선형 계층을 통해 투영함으로써 **순수 신경망 정확도 97.32%**를 달성하고, 상위 통사 규칙과 결합하여 **100% 무결성 E2E 추론**을 구현함.

---

## 🏛️ 2. 신경망 아키텍처 (Neural Architecture)

```text
       [ BERT Backbone (768-dim Hidden Vector) ]
                          │
                          ▼
            Linear Layer 1 (768 ➔ 128)
                          │
                          ▼
                  LayerNorm (128)
                          │
                          ▼
                   GELU Activation
                          │
                          ▼
                    Dropout (0.1)
                          │
                          ▼
            Linear Layer 2 (128 ➔ 2)
                          │
                          ▼
          Logits [ P(NATIVE), P(SINO) ]
```

### ⚙️ 모델 세부 스펙

| 항목 | 세부 내용 |
| :--- | :--- |
| **모델 파일명** | `models/ko/KO_model_counter.onnx` |
| **입력 (Input)** | `hidden`: `[batch_size, 768]` (Float32, BERT INT8 백본 히든 출력) |
| **출력 (Output)** | `logits`: `[batch_size, 2]` (Class 0: NATIVE, Class 1: SINO) |
| **총 파라미터 수** | **98,946개** (약 390 KB) |
| **추론 지연 시간** | **`~0.001 ms` / 문장** (CPU 단독 극초고속 추론) |
| **ONNX Opset** | Opset 14 (MSVC C++ Native DLL 및 Python 완벽 호환) |

## 🏷️ 3. 지원 단위 및 2-Class 분류 정의

8대 다의어 단위 명사에 대해 20 미만 수량(`num_val < 20`)의 문맥을 2개 클래스로 판별합니다. (20 이상은 한자어 대원칙 적용)

| 단위 명사 | Class 0: NATIVE (고유어 수량/빈도) | Class 1: SINO (한자어 서열/식별자/스포츠) |
| :---: | :--- | :--- |
| **번** | 행동 횟수, 빈도 (`3번 갔다` ➔ 세 번) | 출구, 게이트, 버스, 문제 (`3번 출구` ➔ 삼 번) |
| **대** | 구체물/차량 수량 (`차 2대` ➔ 두 대) | 거시 서열, 직책, 세대 (`3대 대통령` ➔ 삼대) |
| **장** | 평면/종이 수량 (`사진 5장` ➔ 다섯 장) | 서적 챕터, 법률 조문 (`제2장`, `3장은` ➔ 이장, 삼장) |
| **동** | 건물 낱동 수량 (`체육관 2동` ➔ 두 동) | 아파트 동, 행정동 (`101동`, `3동 4호` ➔ 백일동, 삼동) |
| **단** | 채소/나물 묶음 (`시금치 2단` ➔ 두 단) | 기어, 서랍, 무술/바둑 (`3단 기어`, `7단` ➔ 삼단, 칠단) |
| **점** | 음식 낱점 수량 (`고기 1점` ➔ 한 점) | 시험/경기 점수, 평점 (`100점 만점` ➔ 백점) |
| **기** | 기계/항공기 수량 (`전투기 3기` ➔ 세 기) | 기수, 임기, 신도시 (`학군단 58기` ➔ 오십팔기) |
| **세트** | 패키지/음식 수량 (`버거 2세트` ➔ 두 세트) | 스포츠 세트, 운동 루틴 (`3세트 경기` ➔ 삼세트) |

## ⚡ 6. 하이브리드 엔진 연동 구조 (Hybrid Pipeline)

SNAP 엔진은 **"100% 확정 통사 규칙(상위 80% 방어) + 2-Layer Neural Head(모호한 20% 분류)"**의 2단계 계층 구조로 동작합니다.

```text
입력 텍스트 ➔ [BERT Backbone] ➔ 768차원 Hidden Vector
                                       │
                                       ▼
                     [Tier 1: 100% 확정 통사 룰셋]
                     ├── 접두사 (제- / 제N장 / 제N기) ➔ 100% SINO
                     ├── 접미사 (-번째) ➔ 100% NATIVE
                     ├── 후치 수량사 ([체언] + [단위] + [조사/동사]) ➔ 100% NATIVE
                     ├── 고정 식별자 (N번 출구/게이트/창구/버스) ➔ 100% SINO
                     └── 대결/비율 스코어 (1대1, 3대0) ➔ 100% SINO
                                       │
                                (미확정 잔여 문맥)
                                       │
                                       ▼
                     [Tier 2: 2-Layer Neural Head]
                     └── 복합 명사구 문맥 비선형 임베딩 추론 ➔ 최종 라벨 확정
```
