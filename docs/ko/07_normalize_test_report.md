# text_normalize_kr — 뉴스 코퍼스 정규화 검증 보고서

**작성일:** 2026-05-27  
**대상 모듈:** `snap/text_normalize_kr.py` + `weights/ko/ko_dict_full.json`

---

## 1. 검증 규모

| 항목 | 값 |
|------|----|
| **코퍼스** | `snap/scripts/data/corpus/news_corpus.jsonl` |
| **총 레코드** | **309,962건** (naver_news/document 88.6% · title 6.6% · summary 4.8%) |
| **1회 샘플링** | 5,000건 (random.sample, 매 라운드 랜덤) |
| **총 라운드** | **28회** = **140,000건** 누적 |
| **검증 방식** | 카테고리별 샘플 육안 검토 (일반/숫자/영어/복합/전화/IP) |
| **파이프라인 크래시** | **0건** (28라운드 전부 5000/5000) |
| **처리 속도** | **16~17ms/문장** (≈ 60문장/초) |

> **주의:** 성공률은 Exception 없이 완료된 건수 기준.  
> 음독 품질(발음이 맞는지)은 라운드별 육안 검토로 평가함 — 자동 채점 없음.

---

## 2. 검증 방법

```
라운드 N: 5,000건 샘플링
  └─ clf.process() → scan() → apply_rules() → apply_spans()
  └─ 카테고리별 샘플 출력 (약 40건 육안 검토)
       ├─ 이슈 발견 → 즉시 수정 (text_normalize_kr.py 또는 ko_dict_full.json)
       └─ 다음 라운드에서 수정 반영 확인
```

## 3. 발견 이슈 및 수정 이력

### ✅ 수정 완료

#### [A] 소수점 숫자 처리 — 신규 구현

| 발견 이슈 | 수정 내용 |
|-----------|-----------|
| `3.4%` → 미처리 (공백 오류) | `_DECIMAL_RE` + `_decimal_to_kor()` 함수 신규 추가 |
| `99.76달러` → 미처리 | 소수점 이하 digit-by-digit 처리 |
| `3.00%` → 공 처리 불명확 | trailing zero → `공공` 보존 |
| `1.3%P` → `일점삼%피` | `%P` 대문자 케이스 미처리 → `'%P': '퍼센트포인트'` 추가 |

#### [B] 단위 처리 미처리 — SUFFIX_UNIT_MAP 추가

| 발견 이슈 | 수정 내용 |
|-----------|-----------|
| `490GWh` → 미처리 | `GW`, `MW`, `kW`, `W`, `GWh`, `MWh`, `kWh`, `Wh` 추가 |
| `326t` → 미처리 | `t`, `kt`, `Mt` 추가 |
| `40mg` → 미처리 | `g`, `mg`, `ug` 추가 |
| `120m` → `백이십엠` | `m`, `mm`, `cm`, `m²`, `m2` 추가 |
| `영점오퍼센트피` → 포인트 누락 | `%p`, `%P` 추가 |
| `50px` → 미처리 | `px` 추가 |
| `100GB` → 미처리 | `GB`, `MB`, `TB` 추가 |

#### [C] Unicode 단위 기호 — UNICODE_UNIT_MAP 추가

| 발견 이슈 | 추가 기호 |
|-----------|-----------|
| `10㎛` → 미처리 | `㎛`(마이크로미터) |
| `144㎐` → 미처리 | `㎐`, `㎑`, `㎒` (헤르츠 계열) |
| `80㎎` → 미처리 | `㎎`, `㎏`, `㎍` (질량 계열) |
| `15㎿` → 미처리 | `㎾`, `㎿`, `㎽` (전력 계열) |
| `㎾h` 복합 | `㎾h`(킬로와트시) |
| 기존 등록 | `㎞`, `㎝`, `㎜`, `㎡`, `㎢`, `㎖` 확인 완료 |

#### [D] 사전 오탐 — ko_dict_full.json 수정

| 발견 이슈 | 원인 | 조치 |
|-----------|------|------|
| `AR1001` → `알천일` | `AR`→`알` 잘못 등록 | **삭제** → `에이알천일` |
| `RA인증` → `라인증` | `RA`→`라` 잘못 등록 | **삭제** → `알에이인증` |
| `1L` → `일엘` | `L`→`엘` 이 단위맵 차단 | **삭제** → 단위맵 처리 |
| `YIP는` → `입는` | `YIP`→`입` 잘못 등록 | **삭제** → `와이아이피` |
| `BoB 백서` → `밥 백서` | `BOB`→`밥` (이름 발음) | **삭제** → `비오비` |
| `BOK`, `MAU`, `DAW` | 영단어 발음으로 오독 | **삭제** |
| `OTT` → 잘못된 음독 | 사전 오류 | **수정** → `오티티` |
| `LED` → 잘못된 음독 | 사전 오류 | **수정** → `엘이디` |
| `DIGICO` 미등록 | KT 브랜드명 | **추가** → `디지코` |

### ❌ 잔류 이슈 (수정 불가 — 구조적 한계)

| # | 현상 | 기대 | 원인 | 해결 방법 |

| 1 | `005380` → `오천삼백팔십` | `공공오삼팔공` | BERT가 sino 라벨 부여 → digit-by-digit 규칙 차단 | BERT semiotic head 재학습 |
| 2 | `000660` → `육백육십` | `공공육육공` | `int()` 변환 시 선행 0 소실 | raw string 길이 기준으로 로직 수정 |
| 3 | `㎾h당` → `㎾에이치당` | `킬로와트시당` | 숫자 없는 단독 단위: `(\d+)` 패턴 미매칭 | apply_rules 전 전처리 함수 추가 |
| 4 | `2.19 m` → `이점일구 엠` | `이점일구미터` | decimal span 선점 후 단위 매칭 실패 | span 처리 순서 개선 |
| 5 | `쿨업Coolup` → `씨오오엘유피` | `쿨업` | 한글+영어 혼합 신조어, 사전 미등록 | 개별 사전 등록 |
